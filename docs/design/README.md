# Дизайн-система SkillLink

Шесть документов от Вани и Серёжи. Это обязательный стандарт интерфейса: расхождение
вёрстки с ними считается ошибкой, а не вкусовщиной.

| Файл | О чём |
| --- | --- |
| [01_Interface.md](01_Interface.md) | Характер интерфейса, кнопки, состояния, поиск, уведомления, доступность |
| [02_Page_Template.md](02_Page_Template.md) | Каркас приложения, боковое меню, шапка, шаблоны страниц и списков |
| [03_Typography.md](03_Typography.md) | Шрифт, размеры, иерархия текста, цвета текста, отступы |
| [04_Colors.md](04_Colors.md) | Палитра, прозрачность, свечения, радиусы, статусы, графики |
| [05_Components.md](05_Components.md) | Состав компонентов и их состояния |
| [06_Motion.md](06_Motion.md) | Движение: длительности, порядок появления, переходы между экранами |

Как это реализовано в коде — [../FRONTEND.md](../FRONTEND.md). Значения из документов
заданы один раз переменными в `src/app/globals.css`; в компонентах чисел-цветов
и px-размеров шрифта быть не должно.

Экспорта макетов (Figma или скриншоты) нет — есть только эти описания. Если макеты
появятся, их место здесь же, и `DESIGN_INTEGRATION.md` нужно сверить с ними поле за полем.
