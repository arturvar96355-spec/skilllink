# SkillLink — Typography & Text Design System

> Единая типографическая система SkillLink.  
> Все страницы сайта, компоненты и состояния интерфейса должны использовать эти правила без самостоятельного переизобретения размеров, шрифтов и отступов.

---

## 1. Основной шрифт

### Основной шрифт — Inter

Использовать **Inter** для всего интерфейса.

Причины:
- хорошо читается в дашбордах и таблицах;
- современно выглядит;
- хорошо работает с русским языком;
- подходит для небольших подписей и крупных KPI;
- визуально соответствует тёмному premium SaaS-интерфейсу SkillLink.

### Резервный стек

```css
font-family:
  "Inter",
  -apple-system,
  BlinkMacSystemFont,
  "Segoe UI",
  sans-serif;
```

Не использовать разные декоративные шрифты для отдельных страниц.

---

# 2. Базовые параметры

```css
html {
  font-size: 16px;
}

body {
  font-family: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
  font-size: 14px;
  line-height: 1.5;
  font-weight: 400;
}
```

Основная цель — плотный, но не перегруженный интерфейс.

Текст должен выглядеть воздушно и аккуратно. Не увеличивать количество текста только ради заполнения пространства.

---

# 3. Иерархия текста

## H1 — главный заголовок страницы

Использование:
- заголовок Dashboard;
- заголовок «Университеты»;
- заголовок «Рекомендации»;
- название крупного раздела.

```css
font-size: 30px;
line-height: 1.2;
font-weight: 700;
letter-spacing: -0.025em;
```

Пример:

**Университеты**

H1 должен быть самым заметным текстовым элементом основной области страницы.

---

## H2 — заголовок крупного блока

Использование:
- заголовки карточек;
- названия крупных секций;
- «Моя статистика»;
- «Ключевые программы».

```css
font-size: 20px;
line-height: 1.3;
font-weight: 650;
letter-spacing: -0.015em;
```

---

## H3 — подзаголовок

Использование:
- небольшие секции;
- заголовки внутренних блоков;
- названия подразделов.

```css
font-size: 16px;
line-height: 1.4;
font-weight: 600;
```

---

# 4. Основной текст

## Body Large

Для важных описаний и introductory text.

```css
font-size: 16px;
line-height: 1.55;
font-weight: 400;
```

## Body

Основной размер интерфейса.

```css
font-size: 14px;
line-height: 1.5;
font-weight: 400;
```

Использовать для:
- описаний;
- таблиц;
- карточек;
- обычных пунктов меню.

## Body Small

```css
font-size: 13px;
line-height: 1.45;
font-weight: 400;
```

Использовать для:
- вторичной информации;
- пояснений;
- дополнительных данных.

## Caption

```css
font-size: 11px;
line-height: 1.35;
font-weight: 500;
```

Использовать для:
- маленьких подписей;
- источников;
- дат;
- служебной информации.

Не использовать Caption для основной информации.

# 5. KPI и крупные цифры

Цифры статистики должны иметь собственную визуальную иерархию.

## KPI Large

```css
font-size: 32px;
line-height: 1.1;
font-weight: 700;
letter-spacing: -0.03em;
font-variant-numeric: tabular-nums;
```

Использование:
- 18 активных связок;
- 92%;
- 87 дней;
- 25 000+ студентов.

## KPI Medium

```css
font-size: 24px;
line-height: 1.15;
font-weight: 700;
letter-spacing: -0.02em;
font-variant-numeric: tabular-nums;
```

## KPI Small

```css
font-size: 18px;
line-height: 1.2;
font-weight: 650;
font-variant-numeric: tabular-nums;
```

Цифры должны иметь одинаковое визуальное выравнивание.

---

# 6. Навигация

Основные пункты Sidebar:

```css
font-size: 14px;
font-weight: 500;
line-height: 1.4;
```

Активный пункт:

```css
font-weight: 600;
```

При hover:

```css
font-size: 15px;
font-weight: 600;
```

Увеличение должно быть очень небольшим и происходить плавно.

```css
transition:
  font-size 160ms ease,
  color 160ms ease,
  opacity 160ms ease;
```

Не делать резкого увеличения текста.

---

# 7. Верхняя навигация

Текст кнопки SkillLink / текущего раздела:

```css
font-size: 14px;
font-weight: 600;
```

Если рядом находится breadcrumb:

```css
font-size: 13px;
font-weight: 500;
```

Текущий элемент breadcrumb:

```css
font-weight: 650;
```

---

# 8. Кнопки


Крупные CTA:



# 9. Badges / Status

Например:

- Активен
- В работе
- Потенциал
- Высокий
- Средний


Badge не должен визуально конкурировать с названием объекта.

```css

```


Например:

Город — 11px / 400

Не использовать чрезмерно маленький текст ниже 10px.

# 15. Цвет текста

Не использовать чистый `#FFFFFF` для всего интерфейса.

Рекомендуемая система:

```css
--text-primary: #F4F1FA;
--text-secondary: #9B95B5;
--text-tertiary: #706A8A;
--text-disabled: #4D4865;
```

### Primary

Для:
- H1;
- H2;
- названий;
- важных значений;
- активных элементов.

### Secondary

Для:
- описаний;
- вторичной информации;
- неактивных пунктов.

### Tertiary

Для:
- дат;
- дополнительных пояснений;
- малозначимой информации.

---

# 16. Neon accent text

Основной акцент интерфейса:

```css
--accent-primary: #C34CFF;
--accent-secondary: #FF4FA3;
--accent-warm: #FF7A4D;
```

Не использовать neon-цвет для больших массивов текста.

Акцент применяется к:
- ссылкам;
- активным состояниям;
- CTA;
- выбранным элементам;
- важным интерактивным действиям.

---

# 17. Стиль текста

SkillLink должен выглядеть как современный premium SaaS / enterprise dashboard.

Текст:

- короткий;
- конкретный;
- спокойный;
- профессиональный;
- без лишнего маркетингового пафоса;
- без длинных абзацев внутри интерфейса.

Предпочтительно:

**Проверить просроченные этапы**

Вместо:

**Нажмите здесь, чтобы перейти к просмотру всех просроченных этапов ваших текущих связок**

---

# 18. Регистр текста

Не использовать `UPPERCASE` для обычных элементов интерфейса.

Правильно:

**Активные связки**

Не:

**АКТИВНЫЕ СВЯЗКИ**

Заглавные буквы допустимы только для коротких технических обозначений, если это действительно необходимо.

---

# 19. Межстрочные интервалы

Рекомендуемые значения:

```css
H1: 1.20
H2: 1.30
H3: 1.40
Body: 1.50
Small: 1.45
Caption: 1.35
KPI: 1.10
```

Крупные заголовки должны быть плотнее обычного текста.

---

# 20. Отступы текста

Стандартная вертикальная система:

```text
4px
8px
12px
16px
20px
24px
32px
40px
48px
```

Не создавать случайные значения вроде:

```text
13px
17px
23px
27px
```

если для этого нет специальной причины.

---

# 21. Выравнивание

Основное правило:

**текст интерфейса выравнивается по левому краю.**

Центрирование использовать только для:
- empty states;
- крупных CTA;
- отдельных KPI;
- модальных окон;
- некоторых компактных badges.

Не центрировать длинные описания и таблицы.

---

# 22. Числа

Для числовых значений использовать:

```css
font-variant-numeric: tabular-nums;
```

Это особенно важно для:
- процентов;
- KPI;
- рейтингов;
- дат;
- количества студентов;
- количества программ;
- статистики.

Числа в одной колонке должны визуально выстраиваться в одну линию.

---

# 23. Правила для AI при создании новых страниц

При создании любой новой страницы:

1. Не придумывать новый шрифт.
2. Не придумывать новые размеры текста.
3. Не создавать собственную типографическую систему.
4. Использовать только значения из этого файла.
5. Для нового элемента сначала подобрать существующий уровень текста.
6. Если элемент похож на существующий компонент — использовать тот же typography token.
7. Не использовать font-weight выше 700 без необходимости.
8. Не использовать размер меньше 10px.
9. Не менять шрифты между страницами.
10. Не использовать декоративные шрифты.
11. Не использовать uppercase для обычных UI-элементов.
12. Сохранять одинаковую иерархию текста на всех страницах.

# 25. Главное правило

**Типографика SkillLink — единая система, а не набор индивидуальных решений для страниц.**

Если новый элемент невозможно точно классифицировать, нужно выбрать ближайший существующий typography token, а не создавать новый размер шрифта.

Все страницы должны ощущаться как части одного продукта.
