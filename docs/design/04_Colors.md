# SkillLink — Colors & Visual Style

> Единая визуальная система SkillLink.  
> Основа — дизайн предоставленных референсов: тёмный premium SaaS / enterprise dashboard с фиолетовой базой, neon-акцентами и мягкими свечениями.  
> Главная задача этого файла — не позволять AI заново придумывать цветовую систему для каждой страницы.

---

# 1. Общий визуальный характер

SkillLink должен выглядеть как:

- современный premium SaaS;
- технологичный;
- дорогой, но не перегруженный;
- тёмный;
- немного футуристичный;
- аккуратный;
- с мягким neon-эффектом;
- с большим количеством воздуха;
- с умеренной прозрачностью;
- без чрезмерного glassmorphism.

В качестве визуальной основы использовать предоставленные изображения интерфейса SkillLink.

**Важно:** прозрачность добавляется немного сильнее, чем в исходных референсах, но элементы всё равно должны оставаться хорошо читаемыми.

---

# 2. Основной фон сайта

Основной фон не должен быть полностью чёрным.

Использовать очень тёмный холодный фиолетовый:

```css
--bg-main: #0C0A18;
```

Дополнительный фон:

```css
--bg-secondary: #100D20;
```

Фон Sidebar:

```css
--bg-sidebar: #0D0B1A;
```

Фон верхней панели:

```css
--bg-header: rgba(13, 10, 27, 0.82);
```

---

# 3. Прозрачность

Карточки и панели должны иметь лёгкую прозрачность.

Основная карточка:

```css
background: rgba(29, 23, 52, 0.72);
```

Вторичная карточка:

```css
background: rgba(24, 19, 45, 0.64);
```

Hover:

```css
background: rgba(40, 30, 68, 0.78);
```

Modal / Floating Search:

```css
background: rgba(24, 18, 43, 0.86);
backdrop-filter: blur(24px);
```

Header:

```css
background: rgba(12, 10, 24, 0.78);
backdrop-filter: blur(18px);
```

### Ограничение

Не делать интерфейс полностью прозрачным.

Карточки должны сохранять собственную визуальную поверхность и не сливаться с фоном.

---

# 4. Glass effect

Использовать glass effect умеренно.

Базовый принцип:

```css
backdrop-filter: blur(18px);
-webkit-backdrop-filter: blur(18px);
```

Для крупных floating-элементов:

```css
backdrop-filter: blur(24px);
```

Не использовать огромные значения blur.

Не делать каждый элемент стеклянным.

Glass effect использовать преимущественно для:

- Header;
- Floating Search;
- Notifications;
- Modal;
- Dropdown;
- крупные floating panels.

# 6. Главный neon gradient

Главный фирменный градиент SkillLink:

```css
linear-gradient(
  135deg,
  #FF4FB3 0%,
  #C84DFF 48%,
  #FF7A45 100%
);
```

Использовать для:

- главных CTA;
- активных кнопок;
- важных highlights;
- контуров логотипов вузов;
- progress indicators;
- selected states;
- небольших декоративных элементов.

Не использовать градиент на больших площадях.

---

# 7. Вторичный gradient

Для менее важных акцентов:

```css
linear-gradient(
  135deg,
  #8B5CF6,
  #C84DFF
);
```

---

# 8. Neon glow

Свечение должно быть мягким.

Главный glow:

```css
box-shadow:
  0 0 24px rgba(200, 77, 255, 0.16);
```

Активный элемент:

```css
box-shadow:
  0 0 20px rgba(255, 79, 179, 0.20);
```

CTA:

```css
box-shadow:
  0 8px 28px rgba(255, 79, 179, 0.20);
```

### Важно

Не делать сильное свечение вокруг каждого элемента.

Glow — это акцент, а не постоянный фон интерфейса.

---

# 9. Границы

Карточки должны иметь очень тонкую границу:

```css
border: 1px solid rgba(150, 120, 220, 0.14);
```

Hover:

```css
border-color: rgba(200, 77, 255, 0.30);
```

Active:

```css
border-color: rgba(255, 79, 179, 0.48);
```

Не использовать толстые borders.

---

# 10. Карточки

Карточка SkillLink должна выглядеть как отдельная мягкая поверхность.

```css
background: rgba(29, 23, 52, 0.72);
border: 1px solid rgba(150, 120, 220, 0.14);
border-radius: 20px;
```

Hover:

```css
transform: translateY(-1px);
background: rgba(40, 30, 68, 0.78);
border-color: rgba(200, 77, 255, 0.28);
```

Transition:

```css
transition:
  background 180ms ease,
  border-color 180ms ease,
  transform 180ms ease,
  box-shadow 180ms ease;
```

Карточки не должны постоянно «плавать» или двигаться.

---

# 11. Кнопки

Все основные кнопки должны быть:

- прямоугольными;
- с сильно закруглёнными концами;
- компактными;
- neon / semi-glass;
- с мягким hover;
- без чрезмерного свечения.

Основная кнопка:

```css
background: linear-gradient(
  135deg,
  #C84DFF,
  #FF4FB3 55%,
  #FF7A45
);

border-radius: 12px;
```

Hover:

```css
filter: brightness(1.08);
box-shadow: 0 8px 28px rgba(255, 79, 179, 0.20);
```

Secondary:

```css
background: rgba(48, 32, 82, 0.65);
border: 1px solid rgba(180, 130, 255, 0.18);
```

---

# 12. Активные элементы Sidebar

Активный пункт:

```css
background: rgba(90, 54, 145, 0.24);
border: 1px solid rgba(180, 100, 255, 0.16);
```

Можно использовать небольшой внутренний glow:

```css
box-shadow:
  inset 0 0 18px rgba(200, 77, 255, 0.06);
```

При hover:

```css
background: rgba(110, 70, 170, 0.20);
```

---

# 13. Логотипы университетов

Это отдельное важное правило.

AI должен по возможности самостоятельно использовать **официальный логотип соответствующего университета**, если он доступен в данных проекта или через разрешённый источник.

Но логотип нельзя просто помещать на случайный квадратный фон.

## Обработка логотипа

Логотип должен визуально преобразовываться в стиль SkillLink:

### Шаг 1

Сохранить узнаваемую форму оригинального логотипа.

### Шаг 2

Выделить внешний контур / силуэт логотипа.

### Шаг 3

Добавить neon-контур с градиентом:

```css
linear-gradient(
  135deg,
  #FF4FB3,
  #C84DFF,
  #FF7A45
);
```

### Шаг 4

Фон контейнера логотипа сделать тёмно-фиолетовым, но отличающимся от основного background сайта:

```css
background: #21183A;
```

Допустимый вариант:

```css
background: rgba(44, 29, 70, 0.90);
```

### Контейнер

```css
width: 48px;
height: 48px;
border-radius: 14px;
```

Контейнер должен хорошо отделяться от карточки.

---

# 14. Важное правило для логотипов вузов

Не изменять настолько сильно, чтобы логотип переставал быть узнаваемым.

Не:

- деформировать логотип;
- менять его пропорции;
- случайно удалять части;
- накладывать сильный glow;
- превращать логотип в абстрактный символ.

Цель:

**официальный логотип + единый визуальный язык SkillLink.**

Если автоматическая обработка официального логотипа невозможна, использовать оригинальный логотип на тёмно-фиолетовой поверхности с мягким gradient glow вокруг контейнера.

---

# 15. Иконки программ

Для образовательных программ нет необходимости использовать официальные логотипы.

AI может самостоятельно выбирать стиль.

Допустимые варианты:

### Вариант A — инициалы

Например:

```text
ПИ
DS
AI
ИБ
ML
```

### Вариант B — абстрактный символ

Например:

- graduation cap;
- code;
- database;
- AI node;
- shield;
- chart.

### Вариант C — сокращение программы

Иконка должна выглядеть как часть единой дизайн-системы, а не как случайный emoji.

---

# 16. Стиль иконок

Иконки должны быть:

- минималистичными;
- line-based или simple solid;
- небольшими;
- с мягким neon accent;
- без сложных реалистичных иллюстраций.

Размер:

```css
16px — маленькие
18px — стандартные
20px — основные
24px — крупные
```

---

# 17. Диаграммы

Все charts должны соответствовать общей neon-системе.

Основной цвет:

```css
#C84DFF
```

Второй:

```css
#FF4FB3
```

Третий:

```css
#FF7A45
```

Для positive / success:

```css
#25E0D2
```

Для warning:

```css

```

Не использовать случайные яркие цвета.

# 19. Circular progress

Использовать:

- тонкий neon ring;
- тёмный внутренний фон;
- крупное значение по центру.

Ring должен быть достаточно тонким, чтобы выглядеть premium.

Не делать огромные кольца.

---

# 20. Графики

Линии графиков:

```css
stroke-width: 2px;
```

Area:

использовать прозрачную версию цвета линии.

Например:

```css
rgba(200, 77, 255, 0.12);
```

Grid:

```css
rgba(150, 120, 220, 0.08);
```

Grid должен быть почти незаметным.

---

# 21. Notifications

Notification panel должен выглядеть как floating glass panel.

```css
background: rgba(24, 18, 43, 0.88);
backdrop-filter: blur(24px);
border: 1px solid rgba(180, 130, 255, 0.16);
box-shadow:
  0 20px 60px rgba(0, 0, 0, 0.32),
  0 0 30px rgba(200, 77, 255, 0.10);
```

Новые уведомления можно выделять небольшим neon dot.

---

# 22. Spotlight Search

Floating Search должен визуально отличаться от обычных элементов.

Форма:

**продолговатый овал / capsule**

```css
border-radius: 999px;
```

Фон:

```css
background: rgba(24, 18, 43, 0.90);
```

Border:

```css
1px solid rgba(200, 77, 255, 0.20);
```

Glow:

```css
0 12px 50px rgba(200, 77, 255, 0.16);
```

При открытии результатов search panel может расширяться вниз, сохраняя ту же визуальную систему.

---

# 23. Фоновые декоративные glow

На крупных страницах можно использовать несколько очень мягких radial gradients.

Например:

```css
background:
  radial-gradient(
    circle at 85% 8%,
    rgba(255, 79, 179, 0.12),
    transparent 28%
  ),
  radial-gradient(
    circle at 25% 90%,
    rgba(120, 70, 255, 0.08),
    transparent 30%
  ),
  #0C0A18;
```

Glow должен быть почти незаметным.

Не превращать фон в яркую абстрактную картинку.

---

# 24. Разделители

Использовать тонкие полупрозрачные линии:

```css
border-color: rgba(150, 120, 220, 0.10);
```

Не использовать яркие разделители.

# 26. Hover

Hover должен быть заметным, но спокойным.

Разрешено:

- немного увеличить яркость;
- изменить background;
- усилить border;
- добавить лёгкий glow;
- поднять карточку на 1px.

Не использовать:

- сильный scale;
- резкое изменение размера;
- агрессивную анимацию;
- постоянное свечение.

---

# 27. Active

Active должен быть визуально сильнее hover.

Можно использовать:

```css
border-color: rgba(255, 79, 179, 0.45);
background: rgba(65, 40, 95, 0.35);
```

И небольшой neon glow.

---

# 28. Disabled

Disabled элементы:

```css
opacity: 0.42;
```

Без glow.

Неактивный элемент должен выглядеть спокойным, но оставаться читаемым.

---

# 29. Shadows

Основная тень:

```css
box-shadow:
  0 12px 40px rgba(0, 0, 0, 0.22);
```

Крупные floating элементы:

```css
box-shadow:
  0 20px 60px rgba(0, 0, 0, 0.32);
```

Не использовать чёрные тяжёлые тени вокруг каждой карточки.

---

# 30. Border radius

Единая система:

```text
8px   — маленькие элементы
10px  — inputs
12px  — buttons
14px  — icon containers
16px  — небольшие карточки
20px  — большие карточки
24px  — крупные panels
999px — capsule / badges / Spotlight
```

Не использовать случайные значения.

---

# 31. Общий визуальный баланс

Страница должна примерно придерживаться принципа:

```text
70% — тёмная поверхность
20% — фиолетовые поверхности / glass
7%  — вторичные цвета
3%  — яркий neon accent
```

Neon должен привлекать внимание к действиям и данным, а не заполнять весь интерфейс.

---

# 32. Что AI НЕ должен делать

При создании новых страниц запрещено самостоятельно:

- менять основную палитру;
- добавлять синий как основной цвет;
- использовать чистый чёрный фон;
- использовать белые карточки;
- создавать новые типы glow;
- использовать случайные gradients;
- делать каждый элемент glassmorphism;
- менять стиль логотипов вузов между страницами;
- использовать случайные цвета для графиков;
- создавать разноцветную радугу;
- добавлять 3D-эффекты без необходимости;
- использовать emoji вместо UI-иконок;
- менять border-radius между похожими компонентами;
- делать neon слишком ярким.

---

# 33. Правило для новых компонентов

Если AI создаёт новый компонент:

1. Сначала использовать существующий background token.
2. Затем существующий border token.
3. Затем существующий radius token.
4. Затем существующий typography token из `03_Typography_and_Text.md`.
5. Затем существующий accent color.
6. Только после этого добавлять уникальный декоративный элемент, если он действительно необходим.

Новый визуальный стиль компонента без необходимости создавать нельзя.

---

# 34. Главный визуальный принцип

SkillLink должен выглядеть так, будто **весь интерфейс был разработан одним дизайнером в одной design system**.

Даже если пользователь переходит:

```text
Главная
→ Университеты
→ НИУ ВШЭ
→ Программа
→ Рекомендации
→ Сотрудничество
→ Личный кабинет
```

цвета, прозрачность, glow, карточки, иконки, границы, кнопки и состояния должны ощущаться одинаковыми.

**Не создавать новый дизайн для каждой страницы.  
Создавать новые страницы внутри существующего дизайна.**
