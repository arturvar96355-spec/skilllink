# Словарь терминов SkillLink

Как называть вещи в интерфейсе, сообщениях API, боте, отчётах и документах. Одна вещь —
одно слово: если на одной странице «связка», а на другой «сотрудничество», человек
решит, что это разные сущности.

Тексты интерфейса проверяет тест `src/shared/testing/i18n-no-anglicisms.test.ts`: он
обходит все строки с кириллицей в `src/` (текст JSX, строковые и шаблонные литералы;
комментарии и регулярные выражения не проверяются) и падает на словах из раздела
«Запрещено». Исключение вносится в список `ALLOW` того же файла — с причиной.

## Термины проекта

| Термин | Что это | Как не писать |
| --- | --- | --- |
| **вуз** | Учебное заведение-партнёр (сущность `University`). Строчными: это нарицательное слово, не аббревиатура в тексте | «ВУЗ», «университет» как общее название |
| **образовательная программа**, коротко **программа** | Программа обучения вуза (`EducationalProgram`) | «курс», «направление» вместо программы |
| **связка** | Связь «вуз — программа — IT-продукт», по которой ведётся работа (`Cooperation`). В интерфейсе всегда «связка» | «кооперация», «сделка», «кейс» |
| **сотрудничество** | Работа с вузом вообще, процесс. Не название записи: запись — «связка» | «партнёрка» |
| **этап** | Один из 14 этапов работы по связке (`WorkflowStage`) | «стадия», «шаг», «пайплайн» |
| **пункт чек-листа** | Задача внутри этапа (`Task`) | «таска», «тудушка» |
| **срок** | Дата, к которой этап или пункт должен быть закрыт; «просрочен» — срок прошёл | «дедлайн» |
| **рекомендация** | Предложение системы, что сделать с программой или связкой (`Recommendation`) | «инсайт», «совет» как название сущности |
| **IT-продукт** | Продукт компании, под который готовят специалистов (`ITProduct`). Пишется латиницей через дефис | «ИТ-продукт», «айти-продукт», «продукт» без уточнения в заголовках |
| **навык** | Навык из справочника (`Skill`) | «скилл», «компетенция» как синоним |
| **дефицит навыка** | Навык, которого рынку не хватает относительно программы (в ТЗ — skill gap) | «гэп», «разрыв» |
| **представитель вуза** | Роль `UNIVERSITY_REP`, работает в кабинете вуза | «вузовский юзер», «партнёр» |
| **менеджер** | Роль `MANAGER`, полное название — «менеджер партнёрств» | «аккаунт-менеджер» |
| **документ** | Договор, письмо, программа и т. п. с версиями и статусом (`Document`) | «доки», «файлик» |
| **встреча** | Встреча с вузом: итоги, участники, договорённости (`Meeting`) | «митап», «созвон» как название сущности |
| **заявка на обучение** | Заявка представителя вуза (`Application`) | «лид», «запрос» |
| **пользователь**, **учётная запись** | Человек в системе и его запись для входа | «юзер», «аккаунт» |
| **вход**, **войти**, **выйти** | Действие входа в систему | «логин», «залогиниться», «разлогиниться» |
| **почта для входа** | Адрес электронной почты, по которому человек входит | «логин» |
| **панель**, **сводка**, **главная** | Экран с показателями | «дашборд» |
| **журнал действий** | Кто, что и когда изменил (раздел «Журнал действий» в настройках) | «аудит-лог», «логи» |
| **выгрузка** / **загрузка** | Файл CSV из системы / в систему | «экспорт/импорт» в заголовках кнопок, «аплоад» |
| **согласование**, **согласовать** | Утверждение документа или решения | «апрув», «апрувнуть» |
| **отклонить**, **скрыть** | Отказ от рекомендации или уведомления | «дисмиснуть» |
| **отзыв**, **обратная связь** | Мнение вуза или пользователя | «фидбек» |
| **уведомление** | Сообщение системы в колокольчике или в Telegram | «нотификация», «пуш», «алерт» |

## Разрешённые технические термины

Их можно писать и в интерфейсе: русской замены, которую поймут быстрее, нет.

| Термин | Почему можно |
| --- | --- |
| **API** | Название интерфейса для программ; в интерфейсе — только в разделах для администратора и в сообщениях об ошибках адреса |
| **CSV** | Формат файла выгрузки и загрузки: его видно в имени файла, и Excel называет его так же |
| **PDF** | Формат файла отчёта |
| **Telegram** | Название сервиса, собственное имя — не переводится и не склоняется кириллицей («в Telegram») |
| **email** | Только как имя поля в API (`email`). В интерфейсе — «электронная почта» или «почта» |
| **IT-продукт**, **IT-специалист** | Устоявшееся написание в ТЗ и концепции |
| **ИИ-помощник** | Русское сокращение; «AI» в интерфейсе не пишется |
| **skill gap** | Термин ТЗ — только в скобках после «дефицит навыка», чтобы связать с ТЗ |
| **токен**, **вебхук** | Термины Telegram Bot API и ссылки на календарь; только в описаниях API для разработчиков и в настройках администратора |
| **чек-лист** | Давно русское слово, есть в словарях |
| **воронка** | Устоявшийся деловой термин: «воронка связок по фазам» |

Если нужного слова здесь нет — сначала выберите русское, потом допишите его в таблицу
терминов, чтобы следующий человек взял то же самое.
